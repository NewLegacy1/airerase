# Editable first-order template

The original page structure, imagery, typography, and styles are preserved. All image and font assets are local.

- Edit dist/index.html to change the text, sections, links, and images.
- Edit dist/store-config.js for prices and your checkout link.
- Edit dist/template.css to override the original styles.
- After editing index.html, copy it to dist/pages/first-order/index.html to keep that route aligned.

Original tracking, third-party apps, and live checkout scripts are removed. Checkout and signup require your store integration. The UI is a standalone template, not an installed Shopify theme.

Reference: https://juced.co/pages/first-order (retrieved September 10, 2026).
